# fpl-advisor-data

Автоматически собираемые данные для мобильного приложения FPL Advisor. Не править руками: файлы перезаписываются каждые ~3 часа.

- `data.json` - срез данных лиги, игроков, плана
- `news.json`, `claude_picks.json` - заметки и решения советника
- `meta.json` - время и размер последней сборки
- `state/fpl.db.gz` - история снимков (цены, владение, журнал событий) для восстановления между запусками

Источник: открытый API Fantasy Premier League. Приватных данных здесь нет.
